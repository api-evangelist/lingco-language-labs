# Lingco Language Labs

> Lingco Language Labs, Inc. operates Lingco Classroom, a cloud language-learning
> platform for schools and universities. Lingco publishes no general-purpose public
> developer API. Its integration surface is standards-based education
> interoperability: an IMS/1EdTech LTI 1.3 tool hosted at class.lingco.io, OneRoster
> v1.1 rostering, a Canvas API client integration, and SSO with Google Classroom,
> Schoology and Clever.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from apis.yml and
the artifacts in this repository. Lingco does not publish its own /llms.txt.

## Integration surface

- [LTI 1.3 Integration in Canvas](https://help.lingco.io/en/articles/10768792-lti-1-3-integration-in-canvas): OIDC third-party-initiated login, AGS grade passback, NRPS roster sync.
- [LTI 1.3 Integration in Schoology](https://help.lingco.io/en/articles/11642193-lti-1-3-integration-in-schoology): the same tool registered in Schoology.
- [LTI Single Sign On with Canvas - Account-Level Installation](https://help.lingco.io/en/articles/8519048-lti-single-sign-on-with-canvas-account-level-installation): district-wide install.
- [Setting Up Canvas API Integration](https://help.lingco.io/en/articles/4379311-setting-up-canvas-api-integration): institution issues Lingco a Canvas developer key; Lingco is the API client.
- [OneRoster Integration](https://help.lingco.io/en/articles/11831372-oneroster-integration): OneRoster v1.1 over REST or full-CSV SFTP.
- [Configuring Lingco SSO with Google and Google Classroom](https://help.lingco.io/en/articles/8733059-configuring-lingco-sso-with-google-and-google-classroom)
- [Configuring Lingco SSO in Schoology](https://help.lingco.io/en/articles/11201127-configuring-lingco-sso-in-schoology)
- [Lingco SSO in Clever](https://help.lingco.io/en/articles/15024126-lingco-sso-in-clever)

## Endpoints

- OIDC initiation: https://class.lingco.io/api/lti1p3/login
- Launch / target link URI: https://class.lingco.io/api/lti1p3/launch
- JWKS (RS256): https://class.lingco.io/api/lti1p3/keys
- Canvas OAuth2 callback: https://class.lingco.io/auth/canvas/callback

Registration is not self-service. Administrators complete an LTI or Canvas setup by
sending the Client ID and Deployment ID (LTI) or App ID, Developer Key and Canvas
domain (Canvas API) to Lingco engineering.

## Notes for agents

- AI usage is restricted at the robots.txt layer on class.lingco.io: Content-Signal
  declares search=yes, ai-train=no, use=reference, and nine named AI crawlers
  (including ClaudeBot, GPTBot, Google-Extended, CCBot) are disallowed. Respect it.
- There is no public API to call, no API key to obtain, no rate limits published, and
  no OpenAPI, changelog, roadmap, SLA, security.txt or vulnerability-disclosure
  program found as of 2026-07-19.
- HIPAA- and PCI-regulated data are contractually excluded from the platform.
